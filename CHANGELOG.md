# Changelog

## 0.1.0

- Initial Orvix language-model provider for GitHub Copilot Chat.
- Discover project-scoped managed and BYOK models from Orvix.
- Stream text, reasoning output, usage, images, and function-tool calls.
- Support multiple isolated Orvix API-key entries and a legacy Secret Storage workflow.
- Persist complete per-key catalogs and retry only safe pre-stream transient failures.
